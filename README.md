# 影之居酒屋

忍者節拍動作遊戲，全十關。純網頁，不需要安裝。

**直接玩**：https://sun16z.github.io/kage-izakaya/

- 2.5D 版：`index.html`
- 3D 版：`game3d.html`

## 操作

| | 鍵盤（壹） | 鍵盤（貳，雙人時） | 手機 |
|---|---|---|---|
| 移動 | WASD | 方向鍵 | 左下角拖曳 |
| 刀（連按五連擊） | J | , | 刀 |
| 瞬身 | K | . | 瞬 |
| 手裏劍 | L | / | 鏢 |
| 煙霧彈 | 空白鍵 | 右 Shift | 煙 |
| 分身斬（氣滿） | U | Enter | 氣 |

3D 版用滑鼠拖曳或 Q / E 轉動視角。也支援手把。

光圈收到鼓面的瞬間出刀就是合拍，傷害加倍。

## 檔案

- `core.js`：介面、音效、光影、角色、特效
- `world.js`：十個關卡的場景
- `play.js`：玩家、敵人、關卡流程
- `style.css`：樣式

兩個版本共用同一套程式，只差鏡頭與場地寬度。畫面用 three.js 繪製，音效全部即時合成，沒有任何外部素材。
