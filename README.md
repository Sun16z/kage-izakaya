# 影之居酒屋

忍者節拍動作遊戲，全十關。純網頁，不需要安裝。

**直接玩**：https://sun16z.github.io/kage-izakaya/

- 2.5D 版：`index.html`
- 3D 版：`game3d.html`

## 操作

| | 鍵盤（壹） | 鍵盤（貳，雙人時） | 手機 |
|---|---|---|---|
| 移動 | WASD | 方向鍵 | 左下角拖曳 |
| 刀（連按五連擊） | J | , | 刀 |
| 瞬身 | K | . | 瞬 |
| 手裏劍 | L | / | 鏢 |
| 煙霧彈 | 空白鍵 | 右 Shift | 煙 |
| 分身斬（氣滿） | U | Enter | 氣 |

3D 版用滑鼠拖曳或 Q / E 轉動視角。也支援手把。

光圈收到鼓面的瞬間出刀就是合拍，傷害加倍。

## 連線合作

兩台裝置可以連線一起打。一個人在標題畫面按「開房間」，把房號或連結傳給朋友；朋友輸入房號按「加入」。房主選關卡後開始。

兩台裝置是直接互連的，不經過遊戲伺服器。同一個 Wi-Fi 下最穩；少數行動網路可能連不上。

## 英文修行

標題畫面的「英文」可以開啟。戰鬥中敵人身上會浮現一句英文並念出來，從三個中文意思選一個（鍵盤 1 2 3，手機直接點）。答對會對那個敵人發動言靈斬，接下來幾秒攻擊力提升；答錯不扣血，但那一句之後會更常出現。過關畫面會列出這關遇到的句子，點一下可以再聽一次。

題庫分兩級：國小高年級（130 句）與生活進階（160 句）。發音使用裝置內建的英語語音。

## 檔案

- `core.js`：介面、音效、光影、角色、特效
- `world.js`：十個關卡的場景
- `play.js`：玩家、敵人、關卡流程
- `english.js`：英文修行的題庫與玩法
- `net.js`：連線合作
- `style.css`：樣式

兩個版本共用同一套程式，只差鏡頭與場地寬度。畫面用 three.js 繪製，音效全部即時合成，沒有任何外部素材。
